Придумай {count} новую планету для фабрики «Конвейеры» целиком: ресурсы и рецепты. Фабрика —
клетки 1×1: бур добывает ресурс с пятна, печь плавит (1–2 вида входа), сборщик собирает (1–3
вида входа), порт продаёт по цене предмета.

- title — название планеты, одно-два слова: «Туманная»;
- about — одна фраза о том, как она выглядит, до 120 знаков;
- feature — чем она особенная для игрока, до 90 знаков;
- resources — 3–4 id ресурсов (латиница через дефис), каждый есть в items с ценой 1 и формой ore;
- items — все новые предметы планеты: {"id", "title" по-русски, "price" целое, "shape" одна из
  ore, ingot, brick, wire, gear, chip, motor, frame, drone, plate, crystal, drop, cell, box, ring, tri,
  "color" вида #A1B2C3}; всего с ресурсами 6–12 предметов;
- recipes — {"at": "furnace" | "assembler", "in": {"id": количество}, "out": "id", "n": сколько
  выходит, "sec": секунды 1–8}; один рецепт на предмет; каждый предмет достижим из ресурсов, без
  кругов; цена выхода × n больше суммы цен входа на 20–60 %;
- goal — id главного изделия (самое дорогое, 3–4 звена от ресурсов, 70–150 за штуку).
