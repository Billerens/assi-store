# Диктофон

Запись встречи, лекции или мысли вслух: одна кнопка, запись идёт отрезками по 5 минут, каждый
отрезок расшифровывается на телефоне (`speech.transcribe`, GigaAM) ещё во время записи, после
«Стоп» — чистка текста, конспект с решениями, задачами и открытыми вопросами (для короткой мысли —
заголовок, теги и, если это поручение, черновик во «Входящих», трата в «Тратах» или
напоминание), архив с поиском по словам и по смыслу. Описание — `docs/modules/recorder.md` в Assi.
Ставится в `modules/recorder`, данные — в `data/recorder/` и `data/recorder.db`, конспекты — ещё и в
долгой памяти (`lib/memory`) и в общей базе `lib/base.js` (`kind: 'event'` для встречи и лекции,
`kind: 'note'` для мысли, `source: 'recorder'`, `amount` — минуты, `data.recordingId`).

Модель не обязательна: без неё абзацы ставятся по паузам между фразами, решения, задачи (кто и до
какого дня), вопросы и темы находятся правилами, поручения мысли («напиши Пете…», «потратил
пятьсот на такси», «напомни завтра в девять…») — тоже правилами. Модели только улучшают:
`recorder.clean` — знаки препинания и абзацы (текст, где модель выбросила или добавила слова, не
берётся), `recorder.note` — заголовок, теги и поручение мысли, `recorder.summary` — конспект
встречи (до 15 000 слов одной просьбой, длиннее или моделью на телефоне — по кускам). Каждый шаг
выключается или ограничивается моделью на телефоне в настройках.

## Что включить на телефоне

- **Микрофон** — Assi спросит при первой записи. **Календарь** — при первой кнопке «В календарь».
- **Модель распознавания речи** (настройки Assi) — без неё отрезки ждут в очереди, экран говорит почему.
- **Работа в фоне без ограничений батареи** для Assi — чтобы запись не обрывалась с погашенным экраном.
- Ярлык на рабочий стол — «Настройки» → «Ярлык на рабочий стол»; виджет — как у любого модуля
  («Последняя: Встреча с Олегом, 42 мин» / «Задач открыто: 4»).
- Правки оболочки (`docs/shell-changes.md`), без которых модуль работает по запасному пути:
  `notify.actions` — кнопки «Пауза», «Отметка», «Стоп» в уведомлении оболочки (без неё модуль
  ставит своё постоянное уведомление с теми же кнопками через свой BroadcastReceiver);
  `transcribe.segments` — время каждой фразы (без неё — время отрезка, абзацы по точкам);
  `job.once` — напоминание о задаче одним заданием (без неё — ежедневное задание на это время,
  которое срабатывает в свой день и убирает себя); `speech.render` — только для проверки на телефоне.

## Как устроено

| Файл | Что делает |
|---|---|
| `main.js` | движок: запись отрезками, пауза на звонок, слушание имени выключено на время записи и возвращается, восстановление после падения (`state.json`), очередь расшифровки, конспект, архив, поиск, задачи, импорт, API |
| `android.js` | MediaRecorder (AAC в m4a, `setNextOutputFile` без разрыва или стоп-старт), уровень звука, нарезка файла без перекодирования (MediaExtractor + MediaMuxer; mp3 по кадрам, wav с заголовком), ffmpeg из Linux Assi как запасной путь, плеер телефона, календарь, своё постоянное уведомление |
| `logic/text.js` | время «12:30», абзацы по паузам, куски для поиска, запрос fts4 с началами слов, оценка и отрывок |
| `logic/extract.js` | числа словами → цифры, даты и время («до пятницы», «завтра в девять»), поручения мысли, конспект правилами: решения, задачи с «кто» и сроком, вопросы, люди из словаря, темы |
| `logic/prompts.js` | просьбы к моделям и проверка их ответов (чистка, мысль, конспект одной просьбой и по кускам) |
| `logic/parts.js` | размер отрезка, имена файлов, активное время без пауз, «мысль или встреча», что чистить ночью, тексты уведомлений и виджета |
| `logic/settings.js` | все настройки с границами (сохраняется только отличие от умолчаний) |
| `tool.js` | голосовой инструмент `recorder`; модуль сам кладёт заглушку `tools/recorder.js` |
| `ui/index.html` | «Запись» (режимы, большая кнопка, таймер, уровень, «Пауза» / «Стоп» / «Отметка», текст по ходу записи, последние записи), «Архив» (поиск, «Встречи», «Мысли», «Лекции», «С задачами» с флажками, файлы из «Поделиться», выбор файла), «Настройки». `?tab=…`, `?q=…`, `?kind=tasks` |
| `ui/item.html` | запись из архива (`?id=&t=<мс>`): заголовок правится, плеер по отрезкам, «Кратко», «Решения» и задачи подсвечивают место в расшифровке, задачи (флажок, кто, срок, «В календарь», «Напомнить», правка), вопросы, люди и темы, поручение мысли, расшифровка со временем и отметками (подпись текстом или голосом), сырой текст, «Повторить» у отрезка с ошибкой, меню «Ещё» |
| `ui/common.js` | вызовы `main.js`, время и длительность словами, плеер записи из отрезков (в экране — через blob, иначе — плеером телефона) |
| `checks.js` | проверки на телефоне (`module_check recorder`), за собой убирают |

Раскладки: сложенный Fold — один столбец, кнопки 64–112 точек; раскрытый — слева кнопки и уровень,
справа текст по ходу; полураскрытый на столе — `@media (vertical-viewport-segments: 2)` или Device
Posture API (`folded` и экран шире высоты): сверху таймер и уровень, снизу кнопки.

Файлы данных: `settings.json`, `state.json` (идущая запись — для восстановления), `imported.json`
(какие файлы из `data/uploads/` уже взяты), `incoming/` (файл, выбранный на экране, пока он
приходит кусками), `<id>/part-NNN.m4a` (звук). Таблицы `data/recorder.db`: `recordings`,
`segments` (отрезки: сырой текст, фразы с временем, чистый текст, состояние очереди), `chunks`
(fts4 для поиска), `vectors` (смысл — роль `embed`), `marks`, `tasks`.

Задания: `recorder:clean` в 04:30 (звук старше 30 дней удаляется, текст остаётся; запись с
«Хранить звук всегда» не трогается), `recorder:remind:<id>` — напоминания о задачах.
События: `power` (очередь «только на зарядке»), `call` (пауза на звонок).

## API для других модулей и агента

`var recorder = require('modules/recorder/main.js');`

| Функция | Что делает |
|---|---|
| `startRecording({ mode, title, tags, link })`, `pauseRecording(by)`, `resumeRecording()`, `stopRecording(reason)` | Запись: `mode` — `auto` / `meeting` / `note` / `lecture`. → `status()`; `stopRecording` → `{ id, durationMs }`. |
| `mark(label)`, `addMark(recordingId, atMs, label)`, `setMark(id, label)`, `removeMark(id)` | Отметки. |
| `status()`, `live(id?)`, `recent(n)`, `list({ kind, query, limit })`, `search(query, { kind, limit })`, `item(id)`, `paragraphs(id)`, `openTasks()` | Состояние и архив; `search` ищет по словам (fts4, начала слов) и по смыслу (если у роли `embed` есть модель), у находки — `hit { score, offsetMs, snippet, by }`. |
| `setTitle(id, title)`, `setTask(id, { text, who, due, done })`, `addTask(recordingId, fields)`, `removeTask(id)` | Правки. |
| `taskToCalendar(id)`, `removeFromCalendar(id)`, `remindTask(id)`, `cancelReminder(id)`, `fireReminder(id)` | Задачи: событие в календаре в день задачи (без даты — завтра) в «Событие в», напоминание в день задачи в «Напомнить в» (без даты — через час). |
| `rebuild(id, { clean, kind, wait })`, `retry(id)`, `keepAudio(id, on)`, `dropAudio(id)`, `remove(id)` | Пересобрать конспект (с чисткой моделью, другим видом), повторить отрезки с ошибкой, звук, удаление со всем (файлы, поиск, память, база, напоминания). |
| `summaryText(id)`, `share(id)`, `copy(idOrText)` | Конспект текстом, «Поделиться», в буфер. |
| `uploads()`, `importFile(path, { mode, title, wait })`, `importBegin(name)`, `importChunk(token, base64)`, `importEnd(token, options)` | Файлы: из «Поделиться» (`data/uploads/`) и выбранные на экране; длинный файл режется на отрезки. |
| `play(file, ms)`, `playerPause()`, `playerStop()`, `playerState()` | Плеер телефона (когда экран не может играть файл). |
| `runQueue()`, `clean()`, `process(id)`, `settings()`, `saveSettings(patch)`, `widget()`, `start()` | Очередь, ночная чистка, обработка вручную, настройки, виджет, запуск. |
| `fromNotice({ act })`, `onCall(event)`, `onPower(event)` | Кнопки уведомления и события. |

События на экраны: `recorder.state` (идущая запись или `null`), `recorder.level` (`{ id, level, ms }`
раз в 200 мс), `recorder.changed` (`{ type, id }`), `recorder.player` (`{ ended }`).

Соседи: «Входящие» — `draftFor(name, text, 'voice', { open: false, copy: false, notify: true })`
по всем падежным формам имени; «Траты» — `addManual({ amount, title, note: 'голосом, проверить', at })`,
без «Трат» — трата в общую базу; «Ачивки» видят записи в базе с `source: 'recorder'`; «Фокус» —
кнопка «Надиктовать итог» на сводке сессии зовёт `startRecording({ title: 'Итог фокуса: …', tags:
['фокус', задача], link: { module: 'focus', id } })`: теги из `tags` остаются у записи первыми,
что бы ни нашёл конспект (`recordings.linkTags`), `link` хранится в `recordings.link` и отдаётся в
`item(id).link`.

Отметки подписываются голосом позже — в записи из архива нажатие на отметку → «Подписать голосом»
(`speech.listen`, слушает до «Подпись отметки голосом — слушать до, с», по умолчанию 20 с; пока
идёт запись, кнопка выключена — микрофон занят). Карточка архива показывает число задач и, если
не все сделаны, сколько открыто. На раскрытом Fold нажатие на задачу подсвечивает её место в
расшифровке (как у решений), правка — карандашом; на сложенном нажатие правит, место — кнопкой
времени.

## Отступления от описания

- **«Напомнить» и поручение `reminder` — своё разовое задание, а не рутина.** Описание: напоминание
  предлагается как рутина (`lib/routines`). Модуль ставит своё задание `recorder:remind:<id>`
  (`job.once`, без правки — ежедневное, которое срабатывает в свой день и убирает себя), поэтому на
  экране «Рутины» его не видно; видно и снимается у задачи в записи («Напомню … · снять»).
  Причины: в `lib/routines` нет разового срабатывания — только `daily` (каждый день или по дням
  недели), `every`, `notification`, `event`, — и рутина при каждом срабатывании отдаёт `do` агенту
  (`ai.run`, просьба к модели), а не показывает текст. Напоминание «в пятницу в 9:00 позвонить в
  банк» рутиной стало бы еженедельным и платным, и снять его после срабатывания было бы некому.
  Когда у рутин появится разовое время без агента, перейти на них.

## На телефоне

`module_check recorder`: настройки, разбор речи в движке, файл, озвученный голосом телефона
(`speech.render`) → отрезок → текст → архив и поиск → экран записи → удаление; **3 секунды записи
с микрофона** (имя на это время не слушается и возвращается) с отметкой → очередь → удаление;
экраны, инструмент, виджет. На время проверок модели, уведомления, поручения, память и смысл
выключены, собственные настройки владельца возвращаются как были.

## Не сделано

- **Ничего не запускалось на телефоне** (adb и эмулятор в этой работе не использовались): ни
  `checks.js`, ни запись. Логика и весь путь `main.js` проверены в подставном движке под node
  (`tests/engine.test.js`), логика — ещё и под Rhino 1.9.2, движковые файлы — компиляцией Rhino,
  экраны — в браузере на подставных данных при ширине 320 и 800. По разделу «Как проверить»
  описания на Fold5 остаётся проверить:
  - MediaRecorder из движка: AAC 16 кГц моно, `setNextOutputFile` на стыке отрезков (фраза ровно на
    5:00 — без пропущенных слов; если следующий файл не приходит, модуль сам переходит на стоп-старт);
  - 40 минут с погашенным экраном и что Samsung не душит запись через 30–60 минут;
  - старт записи, когда Assi свёрнут (ограничения Android на микрофон в фоне), и голосом через агента;
  - пауза на звонок (событие `call`), какой источник звука лучше (`MIC` / `VOICE_RECOGNITION` / `UNPROCESSED`);
  - скорость расшифровки отрезка в 5 минут и расход батареи.
- **Полураскрытый Fold**: поддерживает ли WebView на Android 16 `vertical-viewport-segments` и
  Device Posture API — не проверено; если нет, остаётся обычная раскладка.
- **Играет ли WebView m4a / ogg / amr** из blob — не проверено; если нет, плеер сам переходит на
  плеер телефона (`play`), без перемотки ползунком во время игры.
- **Нарезка без перекодирования** (MediaMuxer) для ogg/opus работает с Android 10 (API 29); amr,
  flac и прочие длиннее 10 минут режутся только ffmpeg из Linux Assi — без него честная ошибка с
  подсказкой. Потоковая расшифровка длинного файла без нарезки и запись звука силами оболочки
  (`audio.record`) — это правки оболочки, не сделаны.
- **Кто говорит** (разделение голосов) не сделано: нужна модель диаризации в оболочке; «кто» у задачи
  — по имени перед глаголом («Олег до среды пришлёт») или «владелец» для «я пришлю».
- **Одновременно с живым разговором** (`live.start`) или непрерывным распознаванием запись не
  начинается — микрофон один; экран говорит почему.
- **Календарь**: запись события через `CalendarContract` (первый видимый календарь) не проверена.
- **Конспект правилами** беднее модельного: «Кратко» — первые фразы равномерно взятых абзацев,
  темы — частые существительные в той форме, в какой сказаны («ремонта»); заголовок правится.
