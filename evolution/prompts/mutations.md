Придумай {count} оригинальных мутаций для игры «Эволюция».
Верни JSON-массив. Русский текст, спокойный научно-популярный тон, короткая читаемая карточка.
id — уникальный идентификатор латиницей и дефисами. Не повторяй названия встроенного пула.

Механика строго ограничена утверждёнными шаблонами из конфигурации игры:
- rarity common, effect producer, producer — целый индекс от 0 до 4:
  0 Колония, 1 Губка, 2 Медуза, 3 Червь, 4 Пловец.
  Множитель берётся из mutation.commonMult либо настройки существующей мутации.
- rarity rare, effect stage: множитель этапа берётся из mutation.rareMult.
- rarity special, effect double-generation: дополнительный выбор после поколения.
- rarity special, effect shell: лишние хищники сохраняются, но не повышают разнообразие без пищи.
Поле producer разрешено только для effect producer.

Нельзя создавать новые виды эффектов, задавать величины множителей, цены, вероятности,
длительности, функции, команды, ссылки или код. Название и описание не должны обещать
эффект сильнее выбранного шаблона. Не используй эмодзи и названия коммерческих игр.

```schema
{"key":"id","fields":{"id":{"type":"string","min":3,"max":40},"title":{"type":"string","min":3,"max":44},"text":{"type":"string","min":15,"max":180},"rarity":{"type":"string","oneOf":["common","rare","special"]},"effect":{"type":"string","oneOf":["producer","stage","double-generation","shell"]},"producer":{"type":"number","min":0,"max":4,"required":false}}}
```
