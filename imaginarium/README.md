# Imaginarium

Самостоятельный модуль Axiko с прогулкой по трём комнатам, книгами на полках и мастерской предметов. Экран находится в `ui/index.html`. Сохранения владельца лежат в `data/imaginarium/`. В обычном браузере для автономного просмотра используется хранилище этого браузера.

В настройках моделей Axiko назначьте текстовые модели ролям `imaginarium.write` и `imaginarium.form`. Первая получает замысел конкретной книги и историю этой книги, вторая — описание вещи и геометрию выбранной редакции. Запросы выполняются только после действий в переплётной или мастерской. Три готовых произведения, чтение написанных глав, помещение и принятые предметы доступны автономно.

Трёхмерная сцена использует локальную копию three.js r160 с лицензией MIT в `ui/vendor/`. Предметы состоят из проверенных данных о формах, кривых и треугольниках. Описание и геометрия сохраняются вместе с экземпляром.
