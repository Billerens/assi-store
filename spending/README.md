# Траты

Расходы, которые записываются сами из пушей и SMS банков: категории, месячный бюджет и «на день»,
подписки до следующего списания, месячный разбор. Описание — `docs/modules/spending.md` в Аксико.
Ставится в `modules/spending`, данные — в `data/spending/`, `data/spending.db` и в общей базе
`lib/base.js` (`kind: 'expense'` с категорией в тегах, возвраты с минусом; доходы — `kind: 'income'`).

Модель не обязательна: разбор — правилами, подписки, бюджет и склейка — кодом. Модель только
разбирает незнакомые форматы (`spending.parse`, по умолчанию лишь модель на телефоне — тексты с
остатками по счетам в облако не уходят без настройки), пишет правило по трём образцам
(`spending.rules`, правило проверяется кодом на образцах), раскладывает новые магазины по
категориям (`spending.category`, пачкой раз в час) и пишет слова месячного разбора
(`spending.review`, получает только цифры).

Samsung Wallet также поддерживается в формате «название карты. продавец сумма BYN» без слова
«Оплачено». Правило ограничено пакетами Wallet и не принимает уведомления о балансе или несколько
сумм сразу. После обновления сохранённая очередь неразобранных сообщений повторно проверяется
в фоне, без передачи текстов модели; при ошибке записи сообщения остаются в очереди для повтора.
Валюта бюджета выбирается в настройках: например, BYN для трат в белорусских рублях. При другой
валюте бюджета операция сохраняется в исходной валюте и ждёт курса, если сеть недоступна.

## Что включить на телефоне

- **Доступ к уведомлениям** для Аксико — без него пуши банков не приходят.
- **SMS**: экран «Траты» спросит `READ_SMS`/`RECEIVE_SMS` при импорте истории (карточка на «Обзоре»
  или «Настройки» → «Импортировать SMS сейчас»).
- **Доступ к истории использования** (по желанию) — чтобы в напоминании о подписке было, сколько раз
  за месяц открывали приложение. Без него напоминание просто без этой строки.
- **Работа в фоне без ограничений батареи** — чтобы операции записывались, когда Аксико закрыт.
- Ярлык на рабочий стол — «Настройки» → «Ярлык на рабочий стол»; виджет модуля — как у любого модуля.

## Как устроено

| Файл | Что делает |
|---|---|
| `main.js` | движок: подписки на `notification` и `sms`, разбор и склейка, таблицы, задания, API для экрана и соседей |
| `logic/money.js` | суммы, валюты, карты, формат «41 200 ₽», курсы ЦБ |
| `logic/parse.js` | отсев кодов и рекламы, общий разборщик, применение правил, проверка ответа модели, «форма» текста |
| `logic/rules.js` | заводские правила: Сбер (SMS 900 и пуш), Т-Банк, Альфа, ВТБ, Озон, Яндекс, Райффайзен, ГПБ, Халва, МТС, Почта, Samsung Wallet, Mir Pay |
| `logic/merchant.js`, `logic/merchants.js` | приведение магазина (`PYATEROCHKA 1234 MOSKVA` → «Пятёрочка») и словарь ~150 магазинов с категориями и пакетами подписок |
| `logic/dedupe.js` | повторы пуш + SMS + кошелёк, холд и списание, покупка за границей и рублёвое списание, переводы себе |
| `logic/budget.js` | месяц бюджета (с 1-го или дня зарплаты), что считается тратой, «на день», пороги, необычные траты, день для соседей |
| `logic/subs.js` | подписки (неделя, месяц, год; день списания может сдвинуться на ± «Подписка: допуск дня» — 3 дня по умолчанию, одинаково для недели, месяца и года; частые покупки в одном месте — не подписка), пробные периоды, напоминания |
| `logic/review.js` | месячный разбор (цифры, слова без модели, просьба к модели) и связь коротких ночей с доставкой еды |
| `logic/settings.js` | все настройки с границами; `logic/view.js` — тексты виджета и уведомлений, поиск, траты из чата |
| `shell.js` | что умеет оболочка (`shell.features`): кнопки в уведомлениях, `lib/usage.js` — и запасной путь без них |
| `tool.js` | голосовой инструмент `spending`; модуль сам кладёт заглушку `tools/spending.js` |
| `ui/index.html` | экран: «Обзор», «Лента», «Подписки», «Источники», «Настройки» (`?tab=…`, `?tx=<id>` — карточка операции) |
| `checks.js` | проверки на телефоне (`module_check spending`), за собой убирают |

Файлы данных: `settings.json` (только изменённые настройки), `rules.json` (свои и выученные правила —
пробуются раньше заводских; `{"id": "sber-push", "off": true}` выключает заводское), `merchants.json`
(свой словарь поверх заводского: `"PYATEROCHKA": {"name", "category", "package"}`), `budget.json`
(бюджет и лимиты отдельного месяца, о каких порогах уже сказано), `reviews.json`, `rates.json`
(курсы ЦБ по дням), `learn.json` (образцы нового формата до правила), `sources.json` (счётчики
приложений, похожих на банк, — без текстов), `state.json`.

Задания: `spending:subs` в 05:00 (поиск подписок), `spending:daily` во время из настройки
(по умолчанию 10:00: напоминания, разбор месяца в первый день месяца бюджета, чистка, отложенные
курсы), `spending:category` раз в час, пока есть магазины без категории.

## API для других модулей и агента

`var spending = require('modules/spending/main.js');`

| Функция | Что возвращает |
|---|---|
| `dayBudget(date?)` | `{ date, allowance, spent, ok }` — дневная норма (остаток бюджета на начало дня / оставшиеся дни), потрачено за день, уложился ли; `allowance` и `ok` — `null` без бюджета. Её зовёт «Здоровье» (`budgetOk`). |
| `month(offset?)` | Месяц бюджета: `{ label, key, start, end, currency, summary, upcoming }`. |
| `overview(offset?)`, `feed(options)`, `tx(id)`, `last(n)` | Данные экрана: обзор, лента (`query`, `category`, `limit`, `all`), карточка, последние операции. |
| `addManual({ amount, title, category, currency, at, type, note })` | Записать трату вручную. |
| `setCategory(id, category, all)`, `setAmount(id, amount)`, `setExcluded(id, on)`, `setInternal(id, on)`, `setNote(id, note)`, `split(id)`, `remove(id)` | Правки операции (общая база правится вместе). |
| `subscriptions()`, `confirmSub(id, yes)`, `setSub(id, fields)`, `cancelSub(id)`, `removeSub(id)`, `runSubs()`, `remind()` | Подписки. `cancelSub` пишет в базу `kind: 'event'` с тегом «подписка отменена» и зовёт `event('subscription.cancel', { id, merchant, amount, at })` у Ачивок и Жизни-RPG, если они стоят. |
| `runReview(key?, { quiet })`, `reviews()`, `sleepLink()` | Месячный разбор и связь со сном (сон берётся из базы: `kind: 'sleep'`, `amount` — минуты, `data.night` — дата утра). |
| `ingest({ title, text, sender, source, at, app, key }, { quiet, noModel })` | Одно сообщение банка через весь путь (для проверок и опытов агента). |
| `importSms(days?)`, `reparse()`, `sources()`, `setSource(kind, id, on)`, `unparsedItem(id)`, `parseWithModel(id)`, `modelUnparsed(id)`, `dropUnparsed(id)`, `ignoreSuggestion(kind, id)` | Источники и незнакомые форматы. |
| `runCategories()`, `retryRates()`, `daily()`, `clean()` | То, что делают задания, — вручную. |
| `settings()`, `saveSettings(patch)`, `setMonthBudget(key, { total, categories })`, `status()`, `rulesList()` | Настройки и состояние. |
| `widget()` | Виджет: «Ноябрь: 41 200 из 60 000 ₽» / «На день: 1 105 ₽» / «Скоро: Кинопоиск 399 ₽, 17.11». |
| `actionNotExpense`, `actionRemindOff`, `actionCancelled` | Кнопки уведомлений (с правкой оболочки `notify.actions`). |

Событие на экраны: `emit('spending.changed', { type, id })`.

В карточке операции кнопка «Это перевод себе» / «Это не перевод себе» есть у любой операции (как в
описании), не только у переводов: банк может прислать перевод между своими счетами как покупку или
пополнение.

## Отступления от описания

Сознательных отступлений сейчас нет: кнопка «Это перевод себе» доступна для любой операции, допуск
дня для недельных подписок — тот же ±3 дня из настроек, что и для месячных и годовых.

## Проверки на компьютере

```
node tests/parse.test.js    # 108 придуманных сообщений 15 банков и кошельков: правила, отсев кодов и рекламы
node tests/logic.test.js    # склейка, холды, переводы себе, бюджет, подписки, разбор месяца, сон
node tests/engine.test.js   # main.js целиком в подставном движке (tests/sim.js: node:sqlite + lib/base.js из Аксико рядом)
```

## Не сделано

- **Реальные тексты банков владельца.** Правила написаны по типичным форматам и придуманным
  образцам (`tests/samples.js`), а не сняты с телефона: банки, карты и точные тексты владельца
  неизвестны. Что не совпадёт — уйдёт в «Источники» → «Не разобрано» (кнопка «Разобрать» отдаёт
  образец агенту) или будет разобрано моделью и выучено правилом. Проверить на Fold5 по разделу
  «Как проверить» описания (оплата телефоном, перевод себе, код, импорт против выписки).
- **Пакеты приложений банков и отправители SMS** в начальных списках — по известным именам, не
  проверены на телефоне; «Источники» показывают приложения с суммами в уведомлениях, которых нет в
  списке, и добавляют их одной кнопкой.
- **Приходит ли событие `sms` при Samsung Messages и SMS из «спама»**, отдаёт ли
  `content://sms/inbox` всё — проверяется только на телефоне.
- **Проверки `checks.js` и экран не запускались на телефоне** (adb и эмулятор в этой работе не
  использовались). Логика и весь путь `main.js` проверены в подставном движке под node, экран —
  в браузере на подставных данных при ширине 320, 360 и 800, движковые файлы — компиляцией Rhino 1.9.2.
- **Кнопки в уведомлениях** («Это не трата», «Не напоминать», «Отменил») появятся только с правкой
  оболочки `notify.actions`; без неё уведомление открывает экран (карточку операции — `?tx=`).
- **Наличные** не учитываются отдельно (открытый вопрос описания): их можно записать голосом
  («запиши: кофе 250») или кнопкой «Добавить вручную».
- **Отдельный бюджет поездки** не сделан: покупки в валюте пересчитываются в валюту бюджета (сумма
  банка или курс ЦБ на дату, потом окончательное рублёвое списание) и идут в общий месяц.
