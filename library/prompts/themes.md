Придумай {count} тем для выставок в игре «Библиотека»: витрина из пяти книг одной ветви знаний.

- название — 2–5 слов, до 40 знаков, с заглавной буквы: «Птицы старых садов»;
- ветвь — точно одно из: Естествознание, История, Словесность, Искусство, Ремёсла, Тайное;
- minKind — с какого вида книг (1–4) подходят на витрину: чем выше, тем строже отбор;
- текст — одна фраза для таблички у витрины, до 140 знаков;
- без реальных людей, брендов и ссылок.

```schema
{"key": "title", "fields": {
  "title": {"type": "string", "min": 3, "max": 40},
  "branch": {"type": "string", "oneOf": ["Естествознание", "История", "Словесность", "Искусство", "Ремёсла", "Тайное"]},
  "minKind": {"type": "number", "min": 1, "max": 4},
  "text": {"type": "string", "min": 10, "max": 140}
}}
```
