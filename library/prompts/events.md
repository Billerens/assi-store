Напиши {count} коротких сценок для событий игры «Библиотека» — что видит библиотекарь. Событие
бери из списка (поле event), сценки к одному событию не повторяй:

- excursion — шумная школьная экскурсия; professor — старый профессор дарит справочники;
- tea — читатель пролил чай на книгу; returned — книгу вернули через двадцать лет;
- quiet — тихий вечер в зале; bookseller — букинист с тележкой у двери;
- bookmark — найдена закладка с пометками; note — записка в переплёте;
- contest — конкурс чтецов; roof — протекла крыша; opendoors — день открытых дверей;
- students — студенты перед сессией; cat — кот-библиотекарь; catalog — рассыпался каталог;
- writer — встреча с писателем.

Название — до 40 знаков; текст — 1–2 предложения, до 160 знаков, без цифр наград (их пишет игра),
без реальных людей, брендов и ссылок.

```schema
{"key": "text", "fields": {
  "event": {"type": "string", "oneOf": ["excursion", "professor", "tea", "returned", "quiet", "bookseller", "bookmark", "note", "contest", "roof", "opendoors", "students", "cat", "catalog", "writer"]},
  "title": {"type": "string", "min": 3, "max": 40},
  "text": {"type": "string", "min": 20, "max": 160}
}}
```
