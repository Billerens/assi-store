Ты дописываешь дерево рецептов игры «Алхимик»: игрок смешивает два элемента (иногда три) и получает новый. В ручном наборе — стихии, вещества, погода, растения, ремёсла, быт и город: от «Огонь + Вода = Пар» до «Поезд + Пещера = Метро». Ты решаешь, что выходит из пар, которых в дереве ещё нет.

Для каждой пары из списка — один объект:
- "pair" — пара ровно как в кавычках в списке (ключи через «+»);
- "kind" — "new" (выходит новый элемент), "existing" (выходит элемент, который уже есть в дереве), "none" (реакции нет);
- для "new" и "existing" — "result": имя результата;
- для "new" ещё "desc" (описание до 120 знаков), "category" (одна из категорий ниже), "glyph" (один из глифов ниже), "colors" (два номера цветов палитры).
Для проверок «одно ли это и то же» — "pair" как в списке (со словом «проверка») и "kind": "same" (это тот же элемент) или "differ" (это разное).

Правила стиля:
- имя — русское существительное в именительном падеже, 1–3 слова, только кириллица, пробел и дефис, до 24 знаков;
- мир природы, ремёсел, быта, мифов и города; без брендов, реальных людей, политики, религиозных фигур, грубостей;
- результат должен быть понятен из ингредиентов: человек, увидевший оба, должен кивнуть;
- не придумывай второе имя тому, что уже есть: если результат — существующий элемент, это "existing";
- результат не может быть одной из стихий и не может быть одним из ингредиентов;
- нельзя получить элемент, из которого сделан один из ингредиентов (Гора + Ветер ≠ Камень, потому что Гора сделана из Камня);
- описание — одно короткое предложение о том, что это и откуда берётся, без кавычек и ссылок;
- «реакции нет» — нормальный ответ: открытия ценны, когда их не слишком много.
