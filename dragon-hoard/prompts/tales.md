Придумай {count} коротких текстов событий для игры про дракона, который лежит на куче золота в
горе. Каждый текст — другой рассказ того же события, одна-две фразы, с лёгким юмором. Событие
выбери из списка (поле event) и не меняй его смысл:

- merchant — заблудший купец оставил выкуп у входа;
- gem — в логове блеснул самоцвет;
- rumor — по тавернам ползут слухи о куче: следующий рыцарь придёт раньше и богаче;
- echo — пещерное эхо подгоняет слуг;
- offering — деревня принесла дары, чтобы её не трогали;
- runaway — слуга-кобольд сбежал с монетой;
- sheep — стадо овец у подножия горы;
- rival — над горой пролетает чужой дракон;
- vein — под логовом нашлась золотая жила;
- quiet — тихая ночь, рыцари не придут;
- prophecy — старуха у костра называет следующих рыцарей;
- envoys — послы короля предлагают дань;
- eclipse — затмение;
- molt — у дракона линяет чешуя.

Текст до 140 знаков, без чисел (их покажет игра), без реальных людей, брендов и ссылок.

```schema
{"key": "text", "fields": {
  "event": {"type": "string", "oneOf": ["merchant", "gem", "rumor", "echo", "offering", "runaway", "sheep", "rival", "vein", "quiet", "prophecy", "envoys", "eclipse", "molt"]},
  "text": {"type": "string", "min": 15, "max": 140}
}}
```
