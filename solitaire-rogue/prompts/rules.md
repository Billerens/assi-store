Придумай {count} новых правил для пасьянса «Цепочка»: хозяев раскладов и реликвий. Пасьянс
такой: на столе открытые столбцы карт, в стопку кладут карту на одну старше или младше верхней,
масть не важна; когда ходов нет, открывают карту колоды. Хозяин раз в круг мешает игроку,
реликвия весь забег помогает. Мир — ночной вокзал, свечи, воск, старые карты.

Каждое правило собрано из одного готового кирпичика — придумываешь только название и текст,
а смысл берёшь из кирпичика как есть. Кирпичики (id, для кого, допустимое n, что делает):

- `deck.cut`, хозяин, n 2–6: колода расклада короче на n карт;
- `see.blind`, хозяин, n 0: открыта одна карта стола, остальные открываются по одной после хода;
- `move.alternate`, хозяин, n 0: ходы чередуются — вверх, вниз, вверх;
- `cols.swap`, хозяин, n 3–10: каждые n ходов два столбца меняются местами;
- `aces.guard`, хозяин, n 1–3: тузы не играются, пока в стопку не легли n короля;
- `candles.leftover`, хозяин, n 2–3: каждая карта на столе в конце стоит n свечи;
- `gold.half`, хозяин, n 0: золото за карты вдвое меньше;
- `match.wrap`, реликвия, n 0: король и туз — соседи;
- `match.step2`, реликвия, n 0: можно класть на два старше или младше, цепочка не растёт;
- `match.parity`, реликвия, n 0: чётные подходят к чётным, нечётные к нечётным;
- `match.suit`, реликвия, n 0: карта той же масти подходит к верху стопки;
- `gold.perCard`, реликвия, n 1–2: +n золота за каждую сыгранную карту;
- `candles.clear`, реликвия, n 1–2: пустой стол даёт ещё n свечи;
- `see.deck`, реликвия, n 1–3: видны n следующие карты колоды;
- `candles.start`, реликвия, n 1–3: +n свечи сразу.

Правила к каждому:

- `title` — у хозяина имя или прозвище (два слова, «Хромой звонарь»), у реликвии — предмет
  («Медный напёрсток»); с заглавной буквы, до 28 знаков;
- `text` — что делает правило, своими словами, но тот же смысл, что у кирпичика, с тем же
  числом n; до 90 знаков, без кавычек-ёлочек внутри;
- `kind` — `host` или `relic`, как у кирпичика; `brick` — id кирпичика; `n` — число из его
  диапазона;
- хозяев и реликвий примерно поровну, кирпичики не повторяй подряд;
- без имён и предметов из известных игр, книг и фильмов, без брендов, эмодзи и ссылок.
