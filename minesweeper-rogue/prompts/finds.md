# Находки

Подготовь {count} оригинальных находок для «Сапёра-рогалика». Русское название до 60 знаков и описание до 240 знаков. Без эмодзи, ссылок, кода, чужих персонажей и названий. Эффект составляется из одного или двух готовых кирпичиков в bricks: hearts (сердце), flags (помощь флагами), movement (движение), visibility (видимость). Значение value — целое 1, для movement допустимо 2. Не добавляй нестандартных операций, полей награды или признаков предварительной проверки.

```schema
{"key":"title","fields":{"title":{"type":"string","min":3,"max":60},"text":{"type":"string","min":10,"max":240},"bricks":{"type":"array","max":2}}}
```

Вложенный объект кирпичика содержит только `brick` и необязательный `value`. Новая комбинация проходит настоящий прогон решателя на 500 полях перед появлением в игре; при отказе используется встроенный контент.
