# Правила хозяев

Подготовь {count} оригинальных хозяев для «Сапёра-рогалика». Название до 60 знаков и понятное русское описание до 240 знаков. Без эмодзи, ссылок, кода и заимствований из коммерческих игр. В bricks ровно один или два готовых кирпичика. Допустимые brick: inverse (обратные числа), swarm (рой), double (двойные), fog (туман), hearts (сердце), flags (помощь флагами), movement (движение), visibility (видимость). У дополнительного value только целое 1; у movement допускается 2. Не придумывай новые поля или операции.

```schema
{"key":"title","fields":{"title":{"type":"string","min":3,"max":60},"text":{"type":"string","min":10,"max":240},"bricks":{"type":"array","max":2}}}
```

Пример данных: `{"title":"Тихий дозор","text":"Туман и один запасной удар сердца","bricks":[{"brick":"fog"},{"brick":"hearts","value":1}]}`. Игра проверяет структуру кирпичиков и решаемость на 500 полях; сама модель не может выдать сертификат проверки.
