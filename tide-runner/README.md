# Гребень · Crestline

Офлайн-раннер для Игротеки Axiko. Курьер бежит по трём полосам причала, перепрыгивает канаты, проскальзывает под парусами и собирает дорожки жетонов. Темп растёт с расстоянием. На правой бирюзовой рампе курьер раскрывает доску. Чем выше он поднимется на гребне, тем больше стоят створы. Полосатый сход у берега переводит серию в очки.

Магнит притягивает жетоны с соседней полосы. Форсаж на 2,5 секунды ускоряет курьера на доске и спасает от одного удара. Оба предмета действуют на сбор жетонов 4,5 секунды по умолчанию. Каждое из трёх улучшений добавляет 1,5 секунды притяжения или двойной награды. Продолжительность ускорения и защиты одинакова при любой экипировке.

Жетоны забегов и реваншей остаются в кошельке. В гардеробе доступны четыре модели курьера, четыре доски и два вида снаряжения. «Большая вода» создаёт новую трассу. Реванш повторяет её с личным призраком. В эллинге есть рейтинги по очкам и дистанции, недельные приливы, тренировка волны и разбор падения. Сохранённые забеги и повторы из версии 0.1 используют исходные правила.

## Запуск

В Игротеке устанавливается пакет `tide-runner` с точкой входа `modules/games/tide-runner/ui/index.html`. В Android и браузерном хабе запись идёт через штатный игровой движок. Для самостоятельного запуска используйте обычную локальную HTTP-раздачу каталога `assi-store`:

```sh
python -m http.server 8090 --bind 127.0.0.1 --directory .
```

Откройте [игру на localhost](http://127.0.0.1:8090/tide-runner/ui/index.html). В этом режиме сохранения лежат в localStorage браузера. Параметр `?lang=en` переключает автономную версию на английский. Стрелки или WASD управляют курьером, P или Escape ставят заезд на паузу.

3D-сцена использует локальную копию Three.js r160 с лицензией MIT в `vendor/LICENSE`. Если устройство не создаёт WebGL-контекст, те же объекты и трасса рисуются геометрическим Canvas-рендерером.

## Проверки

```sh
node --test tide-runner/tests/race.test.cjs tide-runner/tests/economy.test.cjs tide-runner/tests/motion.test.cjs
node tide-runner/tests/hub.cjs
node tide-runner/tests/browser.cjs
```

Последние две команды используют соседний репозиторий Axiko либо каталог из `AXIKO_ROOT`. Браузерная проверка использует Playwright и Chromium, принимает `AXIKO_CHROMIUM_EXECUTABLE` и `TIDE_SHOTS` для тестовых снимков. Внешние сервисы, аккаунт и API-ключи для игры не требуются.
