# Assi Store

Модули и игры для Assi — личного Android-ассистента с редактируемой рабочей средой. Здесь находятся читаемые исходники, каталог `index.json` и инструменты авторов. Само приложение Assi пока находится в закрытом репозитории; APK здесь не поставляется.

В первом каталоге — **40 пакетов: 17 модулей и 23 игры**. Среди них Кузница слияний, Словоплёт, Эволюция, Колония астероидов, Траты, Обои дня и Жизнь-RPG. Описание и проверки каждого проекта лежат в его собственной папке.

## Подключение в Assi

В совместимой сборке приложения откройте **Магазин → Источники → Добавить** и укажите:

```text
https://github.com/Billerens/assi-store
```

Можно указать прямой HTTPS-адрес `index.json`. Клиент читает обязательный индекс, показывает каталог, затем подготавливает план установки или обновления. Репозитории не добавляются автоматически.

До применения доступны список изменяемых файлов, конфликты с локальными доработками и проверка агентом. Данные и сохранения не входят в пакет; конфликтующую локальную правку можно сохранить либо согласовать вручную. Предыдущая установленная версия доступна для отката. Отключение или удаление источника не удаляет установленные модули.

**Пакеты сейчас исполняются с доверием к автору (`trustedLegacy`).** Возможности в манифесте и список доменов не являются работающей песочницей и не ограничивают Java/native-доступ. SHA-256 проверяет целостность загрузки, а не добросовестность кода. Агент читает подготовленные файлы в отдельном ограниченном режиме; его вывод может ошибаться. Устанавливайте код, автору которого готовы доверить возможности Assi.

## Исходники и пакеты

```text
<project>/
  store.json          ID, тип, название, целевой путь, необязательные интеграции
  README.md           описание
  module.json         runtime-дескриптор модуля
  game.json           runtime-дескриптор игры; saveVersion независим от версии пакета
  main.js, sim.js, …   читаемая логика
  ui/                 HTML/CSS/JS интерфейса
  checks.js           проверки в Assi
  tests/              проверки на компьютере, не входят в ZIP
  _data/assets/       старые неизменяемые ресурсы, если есть
```

ZIP имеет структуру `package.json`, `README.md`, `LICENSE`, `code/` и необязательную `assets/`. Он не может записывать `data/`, настройки владельца или содержать установочные хуки. Установщик не запускает код пакета во время подготовки и применения плана.

ID берётся из `store.json`, поэтому папка `life-rpg` соответствует пакету `rpg`. Историческая ежедневная игра `sparks-ring` остаётся в исходниках, но **исключена из первого каталога**: её runtime ID и путь сохранений `daily/2026-11-15` не совместимы с адресацией пакетов v1. Они не переименованы.

У Словоплёта словарь поставляется как ресурс пакета. Если уже существует пользовательский словарь `data/games/word-weaver/assets/dict.txt`, игра продолжает читать его; встроенный используется только при отсутствии старого файла. Обновление не копирует словарь поверх данных владельца.

## Собственный репозиторий

Подойдёт публичный GitHub-репозиторий с `index.json` в корне и ZIP/манифестами в Releases либо другое HTTPS-хранилище. Отдельный сервер магазина не нужен. Для закрытого источника встроенной авторизации пока нет.

Документация: [формат v1](docs/marketplace/repository-format-v1.md), [возможности клиента](docs/marketplace/implementation.md), [проверка агентом](docs/marketplace/agent-review.md). Схемы и образцы лежат рядом; адреса `example.org` в образцах являются заглушками.

Нужны Python 3.10+ и PowerShell 7. Проверки и сборка не обращаются в сеть и не исполняют код модулей:

```powershell
python -m pip install -r tools/store/requirements.txt
python -m unittest discover -s tools/store/tests -p 'test_*.py' -v
python tools/store/build_catalog.py `
  --store . `
  --out ../assi-store-dist `
  --base-download-url https://github.com/Billerens/assi-store/releases/download/v0.1.0 `
  --publisher billerens `
  --licensefile LICENSE `
  --exclude sparks-ring
python tools/store/validate_metadata.py --index ../assi-store-dist/index.json
```

Для своего источника замените владельца, URL загрузки и параметры `--repository-id`, `--repository-title`, `--repository-homepage`; выберите собственные версии и лицензию. [Инструкция сборщика](tools/store/README.md) описывает отчёт и публикацию. ZIP дополнительно проверяют настоящим установщиком в тестовой среде. Уже опубликованную версию нельзя подменять другим архивом — выпускайте новую SemVer.

Пределы: 5 МиБ на ZIP, 20 МиБ после распаковки, 2 МиБ на файл, 512 файлов с манифестом, 1 МиБ на JSON метаданных. Минифицированный или упакованный исполняемый код, внешние скрипты, небезопасные пути и исполняемые бинарники не принимаются.

`install.ps1` сохранён как инструмент разработчика для прямой установки через ADB. Для обычной установки и обновлений используйте Магазин, чтобы получить проверку пакета и план разрешения конфликтов.

## Лицензия

Общая открытая лицензия проекта пока **не выбрана**; пакеты помечены `UNLICENSED`. Публичная доступность исходников сама по себе не выдаёт открытую лицензию. См. [LICENSE](LICENSE).

У сторонних материалов действуют собственные условия. Лицензии словаря Словоплёта сохранены в [word-weaver/_data/assets/LICENSE.txt](word-weaver/_data/assets/LICENSE.txt) и включены в его ZIP без изменений.
