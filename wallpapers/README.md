# Обои дня

Каждое утро модуль находит в открытых источниках фотографию под погоду, сезон и вкус владельца,
режет её под внешний (904×2316) и внутренний (1812×2176) экраны Fold и ставит на экраны и
блокировку. У каждой картинки в истории — название, автор, источник, лицензия и ссылка на
оригинал. Картинки не генерируются: только найденные, только со свободной лицензией.
Подробное описание — `docs/modules/wallpapers.md` в Аксико.

Android-адаптер передаёт флаги установки как числа и явно выбирает `setBitmap(Bitmap, Rect,
boolean, int)`. Это совместимо с настройкой Rhino в Аксико, которая разворачивает Java Integer
в обычное число; отдельный `tests/android.test.js` проверяет этот путь и отказ системы.

## Что включить на телефоне

- **`SET_WALLPAPER` в манифесте Аксико** (п. 16 `docs/shell-changes.md`). Разрешение обычное:
  выдаётся при установке. Без него модуль всё подбирает и кадрирует, а ставить предлагает
  вручную — кнопка «Поставить вручную» открывает системный экран «Установить как обои»
  (картинка кладётся в галерею, `Pictures/Аксико`). Что есть в сборке, видно в «Настройки →
  Состояние».
- **Геолокация (грубая)** — для погоды и полушария. Без неё укажите город в настройках.
- **Ключи Unsplash и Pexels** — по желанию, бесплатные (учётная запись владельца). Вводятся в
  системном окне: «Настройки → Источники → Ключ». Без ключей работают Commons, Openverse,
  Art Institute of Chicago, для космоса — NASA Images и APOD.
- **Модели** — по желанию: роли «Обои: запрос поиска» и «Обои: выбор картинки (нужно зрение)» в
  настройках Аксико. Без моделей запрос собирается по шаблону, выбор — по простой оценке.
- Модуль стартует сам (`autostart` в `module.json`): заводит `job('wallpapers.daily')` на время из
  настроек и слушает `on('network')` для режима «только Wi-Fi».

Правки оболочки, которыми модуль пользуется, если они есть (`native('shell.features')`):
`notify.actions` — кнопки «Вернуть вчерашние» и «В избранное» в уведомлении (без них нажатие
открывает экран); `widget.image` — миниатюра в виджете; `job.once` — точный разовый повтор без
Wi-Fi (без него — `job` каждые N минут, пока не получится).

## Источники и что о них выяснилось (2026-11-14)

| Источник | Ключ | Что учтено |
|---|---|---|
| Wikimedia Commons | нет | Поиск `filetype:bitmap filew:>2399 fileh:>2399` — маленькие отсеивает сам Commons. Берутся только явные CC0 / CC BY / CC BY-SA / PD; HTML в авторе снимается. Миниатюры — только стандартных ширин (500 есть, 400 нет). |
| Openverse | нет | Миниатюры файлов Wikimedia через `/thumb/` Openverse не отдаёт (424) — модуль берёт их у самой Wikimedia. Отсекаются NC и ND. |
| NASA APOD | необязателен | **Сломан:** после переезда apod.nasa.gov на science.nasa.gov API на любую дату отдаёт заглушку `nasa-logo@2x.png` «NASA Science». Модуль распознаёт заглушки и пишет об этом в статусе подбора. Картинки с `copyright` не берутся. Только для космических тем. |
| NASA Images | нет | Добавлен вместо APOD для космоса: оригиналы с размером в `links[rel=canonical]`. Чужие (© в описании) не берутся. |
| Art Institute of Chicago | нет | Сервер картинок IIIF без заголовка `AIC-User-Agent` отвечает проверкой Cloudflare (403) — заголовок документирован, модуль его шлёт. Отдаёт не больше **4,8 Мпикс** (`maxArea` в info.json, читается раз в месяц): при «меньшая сторона ≥ 2400» картины не проходят никогда; при 2100 — проходят квадратные. |
| Unsplash | нужен | Без Unsplash+; оригинал уменьшается на сервере до нужной стороны; после установки — запрос на `download_location` (правило API); ссылки с `utm_source`. |
| Pexels | нужен | Оригинал уменьшается на сервере (`w=`). |

Сохранённые ответы — в `samples/` (настоящие: commons, openverse, nasa-images, aic, aic-info,
apod-placeholder, open-meteo, geocoding; по документации: unsplash, pexels, apod-classic — для
них нужен ключ или API больше так не отвечает). Они ставятся вместе с модулем: на них работают
проверки без сети.

## Как устроено

- `settings.js` — схема настроек (экран рисует форму по ней), значения по умолчанию, нормализация.
- `context.js` — день, сезон по полушарию, погода Open-Meteo (WMO → слово), тема дня по весам с
  запретом серий, запросы от точного к общему, причина выбора.
- `sources.js` — запросы к источникам и разбор их ответов в кандидатов одного вида.
- `select.js` — dHash, яркость, чёткость середины, размер по первым байтам файла, два сита отсева,
  вкус и простая оценка, подсказки моделям и разбор ответов, кадры под шарнир, `inSampleSize`.
- `fold.js` — что нашла разведка отражением и каким способом ставить два экрана.
- `android.js` — сеть (okhttp), чтение и резка больших картинок (`BitmapRegionDecoder` с
  `inSampleSize`), `WallpaperManager`, разведка отражением, место, сеть.
- `main.js` — подбор целиком, история (SQLite `data/wallpapers.db`), расписание, функции экрана
  и агента. Файлы — `data/wallpapers/<день>/inner.jpg`, `cover.jpg`, `thumb.jpg`; оригинал после
  резки удаляется; полные кадры хранятся `keepFiles` дней (избранное — всегда), миниатюры — всегда;
  стёртые кадры пересоздаются из оригинала при «Поставить снова».

Подбор: место и погода → тема (повод из «Праздничных пасхалок», если есть; после короткой ночи —
тема «тишина» с добавочным весом, если включено) → запросы → источники
по очереди (не больше `maxRequests` запросов) → первое сито (размер, повтор за 365 дней, автор за
14, вес файла, люди) → миниатюры: яркость, чёткость, dHash → второе сито (похожие, светлые) →
выбор (модель со зрением или оценка) → скачивание оригинала (не вышло — следующий, всего
`applyAttempts`) → два кадра → установка → история, событие, виджет, тихое уведомление.

**После плохой ночи** (настройка «После короткой ночи — спокойные пейзажи», по умолчанию
выключена — в описании «по желанию»): модуль читает сводку дня «Здоровья»
(`modules/health/main.js` → `today()`, цель сна — `goals().sleepGoal`). Если сон известен и
короче цели на `calmShortMin` (45 мин) и больше, к темам на этот день добавляется «тишина»
(`calmTopic`, запрос `calmQuery` — `calm quiet landscape`) с весом `calmWeight` (6); если у
владельца уже есть тема с таким названием, вес прибавляется к ней. Настройки тем не меняются, в
причине выбора — «после короткой ночи». Нет «Здоровья» или данных о сне — день как обычно.

Второй повод для той же «тишины» — **настроение Питомца** (настройка `calmFromPet`, по умолчанию
«Не учитывать», работает и без настройки про короткую ночь). «Когда он невыспавшийся или сонный»
(`tired`) — состояния `unrested`, `sleepy`; «Ещё и когда притихший или под пледом» (`low`) —
ещё `quiet`, `blanket`. Модуль только читает `data/pet/state.json` (если стоит
`modules/pet/main.js`), состояние другого дня не считается. В причине выбора — «Питомец
невыспавшийся», в контексте дня — поле `petMood`. Нет Питомца — день как обычно.

**Ачивки** «Коллекционер» (`collectorFavorites` = 50 обоев в избранном) и «Путешественник»
(`travellerCountries` = обои из 30 стран): после подбора и после «В избранное» модуль сверяет
`stats()` с порогами и выдаёт ачивку через `require('modules/achievements/main.js').grant(item)`
(`key: 'wallpapers/collector' | 'wallpapers/traveller'`, `source: 'wallpapers'`, группа «Обои»);
пока модуля «Ачивки» нет — кладёт `item` в его ящик `data/games/achievements-outbox.json` (он
разбирает его при старте). Каждая выдаётся один раз (`state.json` → `awarded`); выключается
настройкой `awards`. Страна картинки — поле `country` в истории: у Art Institute — место
создания картины (`place_of_origin`, бывает и регион: «Flanders», «England»), у Unsplash — страна
из ответа поиска или, если её там нет, со страницы фото (`/photos/:id`, один запрос после
установки). Commons, Openverse, NASA и Pexels страны в ответах не дают: у их картинок `country`
пустая, и они «Путешественнику» не засчитываются.

На сложенном Fold (уже 600 px) — одна колонка и превью только внешнего кадра; на разложенном —
оба кадра рядом и кнопки справа.

Два экрана Fold: `foldMode = auto` выбирает так — подтверждённый владельцем флаг внешнего
экрана → `setBitmapWithCrops` (Android 15+: одна картинка из двух кадров и карта «размер экрана →
часть») → один кадр на оба экрана (кадр внутреннего, главное в безопасной середине). Строка в
«Настройки → Экраны» честно говорит, какой способ работает и почему. Флаг, найденный разведкой,
не используется, пока владелец не нажмёт «Проверить», не сложит телефон и не подтвердит глазами.

## Для агента и других модулей

`require('modules/wallpapers/main.js')`:

- `run({ dryRun, manual, topic, query, limit, sources })` — подобрать и поставить (`dryRun` — только
  выбрать и нарезать), `other()` — «Другие сейчас» (лимит в час), `pickTopic(названиеИлиСлова)` —
  «поставь что-нибудь с горами», `setFromUrl(url, title)` — любая картинка по ссылке, по середине.
- `revert()`, `setAgain(id, why)`, `favorite(id, on)` (или `favorite({ id, on })`), `vote(id, 1 | -1 | 0)`,
  `prefer(kind, value, delta)` — «больше не показывай города» → `prefer('word', 'city', -3)`;
  `weights()`, `forgetWeight(kind, value)`.
- `today()`, `history({ limit, offset, favorites })`, `get(id)`, `describe()` — строка «что сейчас
  на обоях», `widget()`, `stats()` — `{ shown, favorites, sources, authors, countries }` для Ачивок;
  `awards()` — проверить пороги и выдать ачивки (зовётся сам после подбора и «В избранное»).
- `weatherNow(maxAgeMinutes)` → `null | { at, latitude, longitude, code, word, snow, temperature, isDay }`
  — погоду берут «Праздничные пасхалки» (первый снег).
- `settings()`, `saveSettings(values)`, `set(key, value)` — «меняй обои в 8» → `set('time', '08:00')`.
- `askKey(source)`, `removeKey(source)`, `keys()`, `askLocation()`, `place()`.
- `probeFold()`, `testFlag(name, withSystem)`, `confirmFlag(works)`, `forgetFold()`, `screenNow()`.
- `applyManually(id)`, `openOriginal(id)`, `daily()`, `retry()`, `start()`, `stop()`, `clean()`, `clearDry(id)`.

События: `wallpapers.changed { id }`, `wallpapers.progress { step, text }`.
Вкус («больше/меньше такого») пишется и в долгую память (`lib/memory`, метки «обои», «вкус»),
если не выключено в настройках.

## Отличия от описания

- **«Хранить полные файлы» — дней, а не штук.** В таблице настроек описания — «30 штук», а в
  его же разделе «Данные» — «полные кадры — последние 30 дней и всё избранное». Модуль держится
  «Данных»: `keepFiles` = 30 дней. При обычной работе это одно и то же (одна картинка в день), а
  счёт по дням не даёт нескольким «Другие сейчас» за день вытеснить кадры прошлых дней, к которым
  ведёт «Вернуть вчерашние».
- **NASA APOD — `count` настройкой** `apodCount` (по умолчанию 10, как в описании); раньше шло
  `min(pageSize, 20)`.
- **Страна** есть не у всех картинок (см. «Ачивки» выше): описание само оговаривает «страна — из
  метаданных, где она есть». Обратного геокодирования по координатам снимка (Commons) нет: нужен
  отдельный сервис, а ачивка того не стоит.

## Не сделано

- **Не проверено на телефоне** — у разработчика модуля не было устройства (adb и эмулятор не
  использовались по условию задачи): установка обоев, поведение `setBitmapWithCrops` на One UI 8,
  есть ли у Samsung флаг внешнего экрана и как он называется, `cmd wallpaper` через Shizuku,
  смена обоев в Doze в 07:00, читаемость текста экрана поверх WebView Samsung. Модуль сделан
  так, чтобы всё это выяснялось на телефоне: разведка пишет `data/wallpapers/fold-probe.json`,
  флаг проверяется глазами владельца, неудачный способ запоминается и больше не пробуется.
- **Вывод разведки Fold не записан в `docs/modules/wallpapers.md`** (этап 2) — документ в
  репозитории Аксико, а его правка была запрещена условием. Записать после «Разведать экраны» на
  телефоне.
- **`lib/boot.js` не трогался**: модуль запускается через `autostart` из `module.json`.
- **Динамический экран блокировки Samsung и обои из тем Galaxy** могут перебивать обои
  блокировки — отключить из приложения нельзя, об этом подсказка в настройках.
- **Material You** перекрашивает систему по обоям — отключается только в настройках телефона;
  подсказка в «Настройки → Состояние».
- **Картинки из общего веб-поиска** не используются: лицензия неизвестна (открытый вопрос
  описания; по умолчанию — нет). Ручная установка «по ссылке» есть.
- **Одно утреннее уведомление вместе с «Тайной жизнью телефона»** не сделано: нужен договор о
  общем уведомлении между модулями.
- **APOD** сейчас ничего не даёт (см. таблицу) — оставлен на случай, если NASA починит API;
  космос идёт через NASA Images.
- **Unsplash и Pexels** проверены только на ответах по документации — настоящих ключей не было.
