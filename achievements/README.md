# Ачивки за жизнь

Достижения за реальную жизнь: сон, шаги, привычки, места, траты, экран и игры Игротеки.
Описание — `docs/modules/achievements.md` в Axiko. Ставится в `modules/achievements`.

## Что включить на телефоне

- **«Здоровье»** (`health`) — сводки дней, пауза и крючки `life.day`, `life.mark`, `life.place`.
  Без него ачивки считаются по записям общей базы (`sleep`, `steps`, `habit`, `screen`, `visit`,
  `expense`…), экран пишет об этом, а группа «Места» прячется, пока о местах ничего не известно.
- Для «Мест» — сбор мест в «Здоровье» и геолокация «Всегда»; для «Экрана» — доступ к статистике
  использования; для «Трат» — модуль Траты.
- По желанию — модель роли «Ачивки: шутливые подписи» (в настройках выключена).

## Как устроено

- 96 стартовых ачивок (`starter.json`: 125 ступеней, 19 скрытых, из них 9 колких; 8 из них выдают
  через `grant()` сами Шляпа, Входящие, Диктофон, Праздники, Траты и Фокус) копируется
  в `data/achievements/list.json`; владелец и агент дописывают свои. Правила — данные: типы `day`,
  `streak`, `count`, `total`, `event`, `records`, `custom`, ступени, редкость, вещи Питомцу.
  Формат для агента — `AGENT.md` (он ставится вместе с модулем; `README.md` установщик пропускает).
- Проверка — при закрытии суток (крючок `life.day`, первым, до RPG и Питомца), после отметок и
  новых мест; запасная работа `achievements:day` в 05:20 закрывает дни, до которых «Здоровье» не
  дошло. Первая проверка смотрит историю (90 дней, а суммы «за всё время» — 730) и выдаёт прошлое
  с пометкой «получено за прошлое».
- Неизвестные данные не рвут серий; дни паузы пропускаются (или рвут серию — настройка).
- Каждая выдача — запись `achievement` в общей базе с `{ id, tier, rarity, xp, retro, source }`:
  RPG берёт оттуда опыт. Вещи — Питомцу (`give`, иначе `data/pet/items.json`) и его праздник.
- Уведомления объединяются в одно; скрытые и колкие приходят тихо (`silent`).
- Скрытые не видны по названию ни на экране, ни в виджете, ни агенту — только их счётчик.

## Что даёт другим

`require('modules/achievements/main.js')`:

- `grant(item)` — для Игротеки, ровно по `games.md`: `{ key, source, category, title, text, at,
  hidden, icon }`, повтор с тем же `key` ничего не делает; `drainOutbox()` разбирает
  `data/games/achievements-outbox.json` (при старте модуля и при каждом закрытии суток);
- `check(date, { only, quiet })`, `event(name, data)`, `onDay(date)`, `onMark(mark)`, `onPlace(place)`;
- `view()`, `cardData()` (карточка главного экрана), `summary()`, `closest(n)`, `recent(days)`,
  `seen(ids)`, `widget()`, `list()`, `validate()`, `preview(entry)`, `define(entry)`, `disable(id, off)`, `flavor()`, `settings()`, `saveSettings(patch)`,
  `tool(args)`, `start()`.

Агенту — инструмент `tools/achievements.js` (`summary`, `recent`, `closest`, `preview`, `add`,
`disable`, `enable`, `settings`, `check`).

## Проверки

- На компьютере: `node tests/rules.test.js` и `node tests/fallback.test.js`.
- На телефоне: `module_check achievements` — правила списка, движок (серия, пропуск, пауза),
  `grant` и повтор, ящик игр, предпросмотр, скрытые, крючки и виджет, экран.

## Не сделано

- **Проверки на телефоне и снимки Fold** не запускались: в этой работе не было ни телефона, ни
  эмулятора. `checks.js` написан и ждёт `module_check`.
- **Картинка значка в уведомлении и в виджете**: нужен `setLargeIcon` в `axiko.notify` и картинка
  виджета (`widget.image` в `docs/shell-changes.md`), а значок для них — нарисовать через
  `android.graphics.Canvas`. Сейчас уведомление и виджет текстовые, значки — только на экране.
- **Карточка на главном экране** (`ui/card.html`, сектор сетки `homeSize` 4x2, можно 2x2 и 4x3)
  проверена только в браузере с подставленными данными; на телефоне ждёт `home.cards` в оболочке.
- **«Охотник за подписками»** ждёт, что Траты позовут `event('subscription.cancel', { merchant })`:
  в `spending.md` такого вызова пока нет. **«Бюджет»** работает, только если сводка дня
  «Здоровья» несёт `budgetOk` от Трат.
- **«Рассвет»** берёт дом из мест «Здоровья» (или из настройки `home`); без них не проверяется.
