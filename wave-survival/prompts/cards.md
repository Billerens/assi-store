Придумай {count} новых карточек улучшений для игры «Последний рубеж». Карточка — это сочетание
готовых кирпичиков эффектов; кода нет, только данные. Хорошая карточка — размен: что-то даёт и
чем-то платит.

Поля:

- `title` — название по-русски, 3–30 знаков, без эмодзи, не повторяя оружие и пассивы игры
  (Искровик, Кольцо лезвий, Веер игл, Мортира, Ледяной след, Серп, Цепная дуга, Импульс, Рой
  дронов, Маяк, Семена, Шаровая молния, Плотная броня, Сердечник, Ускоритель, Линза, Магнитная
  катушка, Лёгкие подошвы, Множитель, Регенератор, Счастливая монета, Заточка, Длинный фитиль,
  Ученик, Колючий панцирь, Прицел);
- `rarity` — `common`, `rare`, `epic` или `legendary`;
- `max` — сколько уровней у карточки, целое 1–5;
- `effects` — от одного до трёх кирпичиков `{"stat": …, "value": …}` за один уровень;
- `text` — одна фраза о том, что карточка делает.

Кирпичики и предел `value` за уровень (по модулю):

| stat | что | предел |
|---|---|---|
| `damage` | урон всего оружия, доля | 0.5 |
| `cooldown` | перезарядка быстрее, доля | 0.5 |
| `projectiles` | снарядов всему оружию, целое | 1 |
| `area` | размер снарядов и зон, доля | 0.5 |
| `duration` | длительность эффектов, доля | 0.5 |
| `speed` | скорость героя, доля | 0.5 |
| `pickup` | радиус сбора, доля | 0.5 |
| `xp` | опыт, доля | 0.5 |
| `luck` | удача, единицы | 20 |
| `regen` | здоровья в секунду | 1 |
| `armor` | минус входящему урону | 1 |
| `hp` | здоровье | 40 |
| `crit` | шанс крита, доля | 0.5 |
| `slow` | шанс замедлить при попадании | 0.5 |
| `freeze` | шанс заморозить при попадании | 0.5 |

Отрицательное значение — плата. Сумма всех `|value| / предел` карточки не больше 1: например,
`damage 0.3` (0.6 предела) и `speed -0.2` (0.4 предела). Сильнее — карточку отбросят.

```schema
{"key": "title", "fields": {
  "title": {"type": "string", "min": 3, "max": 30},
  "rarity": {"type": "string", "oneOf": ["common", "rare", "epic", "legendary"]},
  "max": {"type": "number", "min": 1, "max": 5},
  "effects": {"type": "array", "max": 3},
  "text": {"type": "string", "min": 5, "max": 90, "required": false}
}}
```
