# Питомец

Маленькое нарисованное существо со стебельком на макушке. Настроение — из сводки дня модуля
[Здоровье](../health/README.md) (сон, шаги, экран ночью, отметки), рост — из уровня в Жизни-RPG,
вещи — из Ачивок. Одно существо на всех: питомец отвечает за «какое оно сегодня», RPG — за «каким
стало за месяцы», ачивки — за вещи и полку. Подробное описание — `docs/modules/pet.md` в Аксико.

Ставится в `modules/pet`. Без модуля «Здоровье» работает, но всегда «Спокойный» (данных нет —
это не плохо); без RPG — всегда росток; без Ачивок — без вещей; без Праздничных пасхалок — из
сезонного только зимний шарф.

Соседи по желанию (`links.js`, каждая связь — настройка, без соседа всё как раньше):
«Тайная жизнь телефона» — минуты владельца в телефоне прошлой ночью (`ownerNight(ночь)`) вместо
экрана ночью из Здоровья; «Фокус» — пока идёт сессия, существо «Спокойный», говорит фразами
`focus`, без уведомления и голоса; «Игротека» — игры за сегодня (`kind: 'play'` в общей базе)
прибавляют до 5 очков энергии; «Ачивки» — значки редких и выше встают на полку цветом редкости.

## Что включить на телефоне

1. Поставить вместе со «Здоровьем»: `.\install.ps1 health pet -Serial …`. Модуль запускается сам
   (`autostart`): записывает полные настройки в `data/pet/settings.json` (их читает Жизнь-RPG),
   копирует фразы в `data/pet/phrases.json` (их можно править), подключает крючки `life.mark`,
   `life.place`, `life.day` через `health.hook()`, заводит работу `pet:tick` и подписку на экран.
2. Виджет Аксико на рабочем столе с модулем «Питомец»: текст «Листик · бодрый», «Энергия 82 · сон
   7:40 · 6 100 шагов» и фраза; с правкой оболочки `widget.image` — ещё картинка существа слева.
3. Карточка на главном экране Аксико появляется сама при правке `home.cards`.
4. По желанию (вкладка «Настройки»): имя и палитра; одно уведомление в день; голос телефона
   (`speech.say(text, 'local')`); фраза дня от модели — для неё назначить модель роли `pet.voice`
   (подойдёт дешёвая или на устройстве); ярлык комнаты на рабочий стол (`shortcut.pin`).

## Экран

`modules/pet/ui/index.html`, вкладки:

- **Сейчас** — комната (стена, окно днём и ночью, дверь, полка с вещами ачивок, коврик) с
  существом; строка состояния, энергия, фраза. Касание — подпрыгнуть, подмигнуть или повернуться
  (спящий приоткрывает глаз); долгое касание или кнопка вверху — следующая фраза о самочувствии
  (голосом, если включён). Под комнатой — «Стакан воды» и привычки, которые ещё положены сегодня:
  отметка идёт в «Здоровье», существо сразу пьёт или подпрыгивает. Справа (на раскрытом Fold) или
  ниже — «Почему так» с числами и шкалами, полоса настроений за 14 дней, «Рост».
- **Вещи** — надеть и снять (одна вещь на место); вещи на полке просто стоят.
- **Настройки** — что подключено (Здоровье, крючки, RPG, Ачивки, Праздники, картинка в виджете,
  карточка на главном, ярлык) и все числа модуля.
- **Отладка** — любое из 12 состояний и любая реакция вручную (данные не меняются), рядом одна и
  та же картинка в SVG (экран) и в Canvas (виджет), «Все состояния сеткой» — для снимков.

Анимация на CSS: дыхание, моргание с паузой 3–7 с, у состояний свои движения; при
`prefers-reduced-motion` остаётся только моргание. Без теней и без эмодзи.

## API для других модулей

`var pet = require('modules/pet/main.js');`

| Функция | Что делает |
|---|---|
| `celebrate('level', { level })` | праздник уровня: гирлянда и конфетти `partyHours` ч, реакция и фраза (Жизнь-RPG) |
| `celebrate('achievement', { id, title, rarity })` | держит значок цвета редкости, пока владелец не посмотрит (`seen()`), не дольше `holdDays` (Ачивки) |
| `give({ id, from, slot, worn, rarity?, title? })` → `{ already, item }` | новая вещь; `slot`: `head`, `neck`, `hand`, `shelf`; без `rarity` редкость ищется в определении ачивки `from`; повтор ничего не меняет. `addItem` — то же |
| `items()` → `[{ id, from, slot, worn, title, got }]` | все вещи |
| `wear(id, on)` → список вещей | надеть (`true`) или снять; на место — одна вещь |
| `seen()` → значок (`{ id, title, rarity, shelf }`) или `null` | владелец увидел значок — существо ставит его на полку (`shelf` — id вещи), если редкость не ниже `shelfFrom` |
| `state()` → `{ state, title, name, reason, energy, known, factors, since, phrase, line, date, paused, … }` | состояние сейчас (пересчёт, если старше `tickEvery`) |
| `phrase()` → строка | фраза сейчас (для Гороскопа, Сериала на ночь, обоев) |
| `look(stateId?, reaction?)` → параметры `look.js` | облик с ростом, вещами и сезоном |
| `svg({ state, reaction, room, still, size })` → SVG-текст | существо (и комната) с анимацией; `still` — без неё |
| `png({ state, reaction, size })` → `data:image/png;base64,…` | та же картинка через `android.graphics.Canvas` |
| `preview(t)` → `{ state, title, reason, energy, known, factors, why, phrase }` | настроение для подставленной сводки (как `health.today()`), ничего не пишет |
| `recompute({ tick })` → запись состояния | пересчитать сейчас |
| `onMark(payload)`, `onPlace()`, `onDay(date)` | крючки `life.mark`, `life.place`, `life.day` (вызывает Здоровье) |
| `react(kind)` → вид экрана | реакция: `water`, `habit`, `med`, `level`, `achievement`, `welcome`, `tap` |
| `talk()` → `{ phrase, spoken }`, `say(text)` | следующая фраза; сказать голосом телефона |
| `widget()`, `card()`, `view({ quiet })` | виджет, карточка главного экрана, всё для экрана |
| `tool()` → текст | ответ инструмента `pet_state` |
| `settings()`, `settingsSchema()`, `setSettings(patch)` | настройки |
| `modelPhrases()`, `drawWidget()`, `pin()`, `status()`, `tick()`, `start()`, `stop()` | служебное |

Файлы, которые другие модули читают сами: `data/pet/settings.json` (`name`, `palette`: `moss` |
`clay` | `dusk` | `accent`, `stages`, `banned` — список запрещённых слов, его берёт и Гороскоп),
`data/pet/items.json` (список `{ id, from, slot, worn, rarity, title, badge }`; обёртка `{ items: [...] }` тоже читается).

События на экраны (`assi.on`): `pet.changed` (`{ state, energy }` или `{ item }`) и `pet.react`
(`{ kind, at, phrase, state, info }`).

Порядок крючков в `data/health/hooks.json`: ачивки → RPG → питомец, поэтому существо реагирует уже
на новый уровень и новую вещь.

## Как считается

Всё — из `health.today()`; формулы и таблица состояний — `mood.js`, облик — `look.js`, фигуры —
`shapes.js` (общие для SVG `svg.js` и Canvas `draw.js`), фразы — `phrases.js` и `phrases.json`,
история — `history.js`, настройки и их пределы — `settings.js`.

- Энергия: веса сна, ночного экрана, шагов и отметок (0,40 / 0,20 / 0,25 / 0,15); неизвестное
  делит свой вес между остальными; известно меньше `minKnown` — «Спокойный».
- 12 состояний сверху вниз: под пледом, на отдыхе, спит, разбуженный, невыспавшийся, сонный,
  засиделся, любопытный, довольный, бодрый, спокойный, притихший. «Невыспавшийся» до 14:00 и
  снимается 3 000 шагами. Каждое число — настройка.
- Пересчёт: при открытии экрана, после каждой отметки (крючок), раз в `tickEvery` минут
  (`pet:tick`), при разблокировке и выключении экрана в ночном окне. Сменилось состояние или облик —
  перерисовка `data/pet/widget.png` (с `widget.image`) и `assi.widget.refresh('pet')`.
- Против чувства вины: не умирает, не голодает, не теряет рост и вещи; фразы о себе, а не о
  владельце; каждая фраза (и шаблон, и от модели) проходит список запрещённых слов; пауза — уют;
  после перерыва в `welcomeDays` дней — радость возвращению.
- Фраза дня от модели (`modelOn`, в `modelAt`, роль `pet.voice`): в запрос идут состояние, рост,
  вещи, сезон и **факты сводки дня** — строки «Почему так» (сон к цели, экран ночью, шаги к этому
  часу, привычки, лекарства и вода, новые места); модель берёт из них настроение, но цифры не
  называет. Три фразы — на весь день: они идут по очереди при любом дневном состоянии, пока не
  сменились дата или пауза; ночью («Спит», «Разбуженный») и в день без ответа модели — шаблоны.
- Голос существа — только местный (`speech.say(text, 'local')`); если его нет, существо молчит
  (облачным голосом не говорит).
- `prefers-reduced-motion`: остаётся только моргание — дыхание, покачивания, взгляд зрачков
  («Любопытный», «Засиделся»), «Z», пар и прыжки выключены.

## Данные

- `data/pet/state.json` — `{ state, reason, energy, known, factors, since, phrase, line, date,
  reaction, party, holding, lastSeen, model, … }`.
- `data/pet/history.json` — строка в день `{ date, morning, evening, energyAvg, states }`, хранится
  `historyDays` (2 года).
- `data/pet/items.json`, `data/pet/settings.json`, `data/pet/phrases.json`, `data/pet/widget.png`.
- В общую базу питомец ничего не пишет.

## Правки оболочки

`widget.image` (картинка в виджете; без неё — текстовый виджет), `home.cards` (карточка на главном;
без неё — только экран), `notify.actions` (своё `id` у ежедневного уведомления, тихий канал; без
неё — обычное уведомление), `off` (отписка от экрана в `stop()`; без неё — подписка заменяется
пустой). Всё проверяется через `native('shell.features')`.

## Проверки

На телефоне — `module_check pet` (`checks.js`): сценарий описания (сон 300 мин и 60 мин ночью →
«Невыспавшийся», 3 000 шагов → другое состояние) на подставленной сводке; пауза, ночь, мало данных;
все шаблоны фраз через фильтр (и копия владельца); пересчёт и история; все 12 состояний в SVG и
PNG; виджет; вещи (одна на место); праздники; крючки и реакция на воду; инструмент; экран с
вкладкой отладки. Всё, что проверки меняют, они возвращают.

На компьютере — `node tests/pet.test.js`: формулы, таблица, «Почему так», строка виджета, облик всех
состояний, вещи и сезон, отрисовка всех обликов в SVG и через Canvas-подобный рисовальщик (без NaN,
только цвета `#RRGGBB`), разбор путей, фразы и фильтр, ответы модели, история.

## Отличия от описания

- **`careScore` учитывает долю дня**: `сделано / (положено × доляДня)`, не больше 1, а до 08:00
  (доля дня 0) — «неизвестно» (вес отметок делится между остальными). В описании — простое
  отношение. Простое отношение утром всегда около нуля: привычку «на вечер» и вечернюю таблетку
  в 09:00 сделать нельзя, и энергия каждое утро падала бы до 15 пунктов только потому, что день
  начался. Это противоречит правилам описания «неизвестное не считается плохим» и «существо ни в
  чём не упрекает». Доля дня — та же, что у `activityScore` в описании (0 до 08:00, к 21:00 — 1),
  так что к вечеру формула совпадает с простым отношением. `mood.js` → `factors`.

## Не сделано

1. **Проверка на телефоне.** Ни `checks.js`, ни сценарии описания не запускались на устройстве
   (по заданию — без adb и эмулятора). Логика проверена тестами в node, `main.js` вместе с
   `health/main.js` — прогоном в поддельном движке на компьютере, экран и карточка — в браузере с
   поддельным `assi` на ширине 320 и 760 точек. Остаётся: «ночью разблокировать — виджет за минуту
   “Разбуженный”, выключить экран — “Спит”», «отметить воду на экране Здоровья — питомец пьёт» и
   главная проверка смысла — неделю сверять утренний виджет с ощущением.
2. **Картинка через настоящий `android.graphics`.** `draw.js` проверен на записывающем
   рисовальщике, а не на `Canvas` телефона: выбор перегрузок Rhino (`Canvas.rotate/scale`,
   `Paint.setARGB`, `Path.cubicTo`) и то, что PNG совпадает с SVG, нужно посмотреть на вкладке
   «Отладка» (там обе картинки рядом).
3. **Свежесть виджета утром без открытия приложения** (`updatePeriodMillis` 30 мин плюс
   `assi.widget.refresh`) — проверяется только на телефоне. Со своей стороны `widget()` сам
   пересчитывает состояние, если оно старше `tickEvery`.
4. **Палитра «Цвет темы» в виджете**: экран берёт `var(--accent)`, а картинка виджета — постоянный
   `#8B7CFF`: движок не знает текущий цвет темы.
5. **Фраза дня от модели и голос** не проверены с настоящей моделью роли `pet.voice` и голосом
   телефона; ответ модели проходит фильтр слов, при пустом ответе остаются шаблоны.
6. **Выбор формы из 3–4 эскизов** (открытый вопрос) — не сделано: форма одна, имя и палитра —
   настройки. Остальные открытые вопросы решены настройками: уведомление по умолчанию выключено,
   голос выключен, «Разбуженный» ночью включён (можно выключить), одно существо, а не «спутники».
7. **«Посмотрел значок»** считается так: значок опускается кнопкой «Видел» или сам через
   `reactSeconds × 2` секунд на открытом экране. Подходит ли это владельцу — узнать у него.
